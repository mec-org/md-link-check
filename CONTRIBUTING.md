# Contributing

md-link-check is public, but it accepts issues and pull requests only from collaborators. An outside contributor — any GitHub user who is not a collaborator on this repository — may read, clone and fork the code, but issues and pull requests opened by outside contributors are closed without review.

See [PROJECT.md](PROJECT.md) for the project's users, scope and non-goals, and [ROADMAP.md](ROADMAP.md) for the milestones.
